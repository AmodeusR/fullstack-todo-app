# Afazeres

A simple NextJS Todo app for practicing NextJS's paradigms

Uma simples aplicação NextJS de Afazeres para praticar os paradigmas do NextJS

## Como rodar (How to run)

Just run the commands below and the app will be ready to go
Apenas rode os comandos abaixo e a aplicação estará pronta para rodar

```js
npm i
npm run dev
```
